TECHNICAL OVERVIEW / DÈLGHEM

FEM software for Mac. Built for Apple Silicon.

DÈLGHEM is structural engineering software being developed natively for macOS. One workspace for building FEM models, reviewing available analysis results and creating engineering documentation.

Development build · vAlpha1 release planned for January 2027

ARM64 / macOS

What does “native for Apple Silicon” actually mean?

An ARM64 macOS build can run machine instructions compatible with Apple Silicon. Unlike a Windows application running inside a virtual machine, it does not require Windows Arm to be started through virtualization software. This does not mean that every analysis is automatically faster: meaningful performance comparisons require equivalent hardware and structural models.

Frequently asked questions

Is a commercial release already available?

Not yet. A vAlpha1 release is planned for January 2027. The application remains in development and availability will be announced separately.

Do I need a virtual machine to use DÈLGHEM?

DÈLGHEM is designed to run natively on macOS with Apple Silicon, without starting Windows in a virtual machine.

Can I get in touch or contribute?

Yes. The presentation includes a project contact address and options for making voluntary contributions to development.
